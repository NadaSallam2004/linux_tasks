# 🐧 ITI Linux & Shell Scripting — Task Log

A running log of hands-on Bash and Linux exercises from the ITI Embedded Systems track — every task actually run, screenshotted, and reviewed rather than just written and submitted.

Each folder below is self-contained: its own `README.md`, its own screenshots, and — where relevant — its own script.

---

### 🧭 About This Repo

This repo collects small, focused Linux/Bash tasks that build up core command-line and scripting skills: arithmetic and control flow, environment variables, shell customization, PATH management, input validation, and simple system-monitoring tools. Each task page walks through the requirement, the implementation, the actual test run, and — when something didn't work as expected — an honest breakdown of what was wrong and how to fix it.

### 🧠 Skills Practiced Across These Tasks

- Bash scripting fundamentals — variables, `read`, arithmetic expansion, `case`, loops
- Shell environment customization — `~/.bashrc`, `PATH`, persistent variables
- Input validation with regex (`[[ =~ ]]`)
- Command substitution and system-info commands (`date`, `hostname`, `whoami`, `pwd`, `uptime`)
- Reading and debugging real script errors, not just happy-path output
- Documenting a task with screenshots and a clear pass/fail verdict
